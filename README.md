# CubeLink Mission Studio 2.0

안산공고 20명 이상, 180분 로봇팔 체험용 독립 웹앱. **가상·USB 통합 시험판**입니다. PC Chrome/Edge에서 지원 펌웨어 v1.5.5를 연결해 같은 블록을 실물로 실행합니다. 실제 장비 검증은 아직 필요합니다.

## 실행

Node.js 20 이상에서 추가 설치 없이:

```sh
npm start
```

브라우저에서 http://127.0.0.1:5182 를 엽니다. ES 모듈과 모델 로딩 때문에 index.html을 직접 더블클릭하지 마세요. HTTPS 정적 호스팅에는 `dist` 전체를 업로드합니다. 외부 CDN이나 외부 폰트에 의존하지 않습니다.

```sh
npm test
```

## 포함 기능

- 요청된 기본 24개 + 추가 도전 2개. 목표, 난이도, 시간, 시작 상태, 실제 결과 판정, 점진적 힌트, 재도전.
- Blockly 관절·그리퍼·자세·작업대 이동·대기·횟수/계속 반복·거리 조건과 else·센서 읽기/설정·정지.
- 실제 CubeLink GLB 5부품, 기존 조립 피벗과 회전 방향, 카메라 orbit/zoom/reset.
- 여러 큐브의 위치, 최상단 집기, 집게 부착 운반, 놓기 후 작업대/바닥 접촉, 3층 적재.
- 미션별 브라우저 자동 저장, 코드 JSON 내보내기/불러오기, 완료 기록, 미션별 100점.
- 모바일 숫자 입력용 inputmode, 반응형 화면, 실행 중 편집 잠금, 취소 가능한 반복/대기/이동.

`작업대 이동`은 역기구학으로 높이를 계산하는 **가상 학습 보조**입니다. 실물에서는 가상 좌표 대신 교사가 해당 세션에서 저장한 작업대 자세를 사용합니다. 색 인식 센서가 있는 것으로 표시하지 않으며 큐브 색은 가상 과제 데이터입니다.

## 수업 180분

|구간|활동|
|---|---|
|0~25분|구조·서보·4관절·집기·전원 이론|
|25~85분|가상 미션 1~12, 필수 1~8·선택 9~12|
|85~95분|실제 장비 배포·코드 저장|
|95~110분|검증 장비 연결·시작자세·한 관절씩 점검|
|110~160분|교사 검증 Studio로 실물 운반, 13~18 원리 응용|
|160~180분|19~24 중 최종 과제 선택·결과 공유·정리|

24개 전부 완료를 180분 필수 목표로 잡지 않습니다. 13~24도 웹앱에서 가상 연습 가능합니다. 실물 수행 결과는 교사가 확인하며 이 앱은 실물 자동 판정을 제공하지 않습니다.

## 구성

- `dist/core.js`: 기구학, 큐브 상태, 취소 가능한 실행 엔진. USB 접근 없음.
- `dist/missions.js`: 26개 과제와 실제 상태/이벤트 판정. 14·17은 두 센서 입력 검사.
- `dist/blocks.js`: Blockly 어댑터, XML 저장과 실행 트리 변환. eval 사용 없음.
- `dist/simulator.js`: Three.js와 원본 GLB 렌더링.
- `dist/hardware.js`: Web Serial 연결·정확한 펌웨어 확인·초기화·각도 제한·정지·안전 종료. `hardware-runner.js`는 같은 실행 트리를 물리 명령으로 처리하고 `hardware-ui.js`는 통합 화면을 연결합니다.
- `dist/app.js`: 화면, 미션별 저장, 학습 흐름.
- `test/core.test.js`: 자동 검사 35개. `test/make-fixtures.js`: 별도 브라우저 QA 입력 생성기.

## 검증 범위와 남은 작업

자동 검사: 26개 미션의 성공/빈 프로그램 실패, 거리 조건 양쪽 입력, 잘못된 목적지, 적재 접촉, 최상단 집기, 각도 제한, 실행 중 정지/재실행, 무한 반복 취소, 시간/블록 한도. 브라우저에서 Blockly 편집·숫자 입력·저장 복원·미션 1과 8 실행 및 판정을 직접 확인했습니다. 상세 결과는 TEST_REPORT.md 참조.

실물 USB 소프트웨어 경로는 구현했으며 모의 USB를 포함한 전체 53개 테스트가 통과했습니다. 실제 Arduino Nano 연결·안전 정지·초기화·관절 방향·파지, Android USB 및 20대 동시 사용은 미검증입니다. 시뮬레이션은 접촉/적재를 기하학적으로 계산하며 충돌·힘·마찰·서보 전류를 재현하는 물리 엔진은 아닙니다. 실물 수업에는 검증된 기존 CubeLink Studio와 교사 안전 점검이 필요합니다.

저장자세는 90/30/160/90, 가상 시작자세는 90/60/130/120입니다. 가상 시작자세를 실물 안전 자세로 확정하지 않았습니다. 기존 펌웨어 S,pin,angle 및 R/I/K, INIT_OK, PARK_90_30_160_90 규격을 확인했으나 통합판은 지원 펌웨어 확인과 사용자의 저장자세 확인·초기화를 거친 뒤에만 제한된 USB 명령을 전송합니다. 상세한 제한과 사용 순서는 HARDWARE_GUIDE.md를 확인하세요.

학급 진도를 서버로 수집하지 않습니다. 브라우저 데이터 삭제나 다른 기기로 이동하기 전에 코드 파일을 저장하세요. 현재 Site는 사용자 요청에 따라 공개 상태이며 로그인 없이 접속할 수 있습니다. 180분 수업 운영 안내는 이 교사용 문서에만 보존하고 학생 웹 화면에서는 제거했습니다.
