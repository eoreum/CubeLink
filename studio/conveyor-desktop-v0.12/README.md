# CubeLink Conveyor Studio v0.12.0

CubeLink Studio와 분리된 Windows용 컨베이어 전용 패키지입니다. 기존
`studio/web`, `studio/electron`, `studio/desktop-v4`는 변경하지 않습니다.

## 포함 기능

- Electron 기반 Windows 설치형/포터블 실행본
- Arduino Nano/CH340 후보 COM 포트 우선 표시
- 포트 재검색, 연결 해제, 같은 COM 포트 자동 재연결
- 여러 포트의 `HELLO`, `STATUS`, `HELLO?` 응답을 이용한 펌웨어 식별
- 식별 문자열이 없는 구형 펌웨어의 수동 포트 연결
- 포트 점유/드라이버/USB 케이블/보드 미인식 안내
- 실제 모터 제어, HC-SR04 텔레메트리, 디지털 트윈 동기화
- 기존 9개 미션, Blockly, 자동 저장, 3단계 접기, 성공 기록
- 앱 내부 Blockly 번들(인터넷 연결 불필요)

## 펌웨어 핀맵

현재 권장 펌웨어는 `CubeLink_Conveyor_Firmware_v1_2`입니다. 전원만 켠
독립 상태에서는 초음파 거리 5 cm 미만을 감지하면 정방향 60%로 3초
운전하고, Studio의 정상 명령을 받으면 즉시 정지한 뒤 Studio 전용 제어로
전환됩니다. 상세 동작과 업로드 순서는 펌웨어 폴더의 안내서를 참고합니다.

| 기능 | Nano 핀 |
|---|---|
| PWMA | D3 |
| AIN1 | D7 |
| AIN2 | D8 |
| STBY | D12 |
| HC-SR04 TRIG | D4 |
| HC-SR04 ECHO | D5 |

Nano는 컴퓨터 USB에서 전원을 받고, 모터 전원은 별도 배터리에서 모터
드라이버 VM으로 공급합니다. Nano, 모터 드라이버, 배터리의 GND는 공통으로
연결해야 합니다.

## 연결 확인 순서

1. 모터를 벨트에서 분리하거나 벨트를 무부하 상태로 두고 펌웨어를 업로드합니다.
2. 앱을 실행하고 `재검색`으로 Nano/CH340 COM 포트가 보이는지 확인합니다.
3. `자동 찾기`가 CubeLink Conveyor 응답을 식별하는지 확인합니다.
4. 속도 20%에서 정방향, 정지, 역방향, 정지를 각각 확인합니다.
5. 초음파 센서 앞 물체를 이동해 거리 표시가 실시간으로 변하는지 확인합니다.
6. 실행 중 USB를 뽑아 끊김 표시를 확인한 뒤 같은 포트로 다시 연결해 자동 재연결을 확인합니다.
7. Arduino IDE 시리얼 모니터로 포트를 점유한 상태에서 원인 안내가 표시되는지 확인합니다.
8. COM 포트가 여러 개인 PC에서 CubeLink 펌웨어가 있는 포트가 자동 선택되는지 확인합니다.
9. 식별 문자열이 없는 구형 펌웨어는 포트를 직접 선택하고 경고 후 수동 연결되는지 확인합니다.

실제 모터 회전 방향과 속도는 모터 배선/감속기/전원 조건에 따라 반드시 현장에서
확인해야 합니다. 이 빌드는 코드 및 패키징 검증 후보이며 물리 하드웨어 검증 전에는
정식 배포본으로 표시하지 않습니다.
