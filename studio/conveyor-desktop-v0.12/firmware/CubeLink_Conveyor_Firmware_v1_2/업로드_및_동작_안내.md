# CubeLink Conveyor 펌웨어 v1.2.0

## 기본 독립 운전

- Nano에 전원만 공급되고 Studio 명령이 없으면 독립 운전 모드입니다.
- 전원을 켠 뒤 2초 동안 정지 상태로 대기합니다.
- HC-SR04가 `5 cm 미만`의 물체를 감지하면 컨베이어가 정방향 60%로
  3초간 움직인 뒤 자동 정지합니다.
- 같은 물체 때문에 계속 반복되지 않도록, 거리가 `8 cm 이상`으로 멀어진
  뒤에만 다음 물체를 다시 감지합니다.
- 센서 응답이 없을 때는 모터를 출발시키지 않습니다.

## Studio 연결 시

- CubeLink Studio가 `HELLO`, `STATUS` 또는 모터 명령을 보내면 즉시
  독립 운전을 끝내고 모터를 정지합니다.
- 그 뒤에는 Studio의 수동 버튼이나 블록 명령만 따릅니다.
- 독립 운전으로 돌아가려면 Studio 연결을 끊고 Nano 전원을 다시 켭니다.

## Arduino IDE 업로드

1. `CubeLink_Conveyor_Firmware_v1_2.ino`를 Arduino IDE에서 엽니다.
2. 보드를 `Arduino Nano`로 선택합니다.
3. CH340 계열 구형 Nano는 프로세서를 `ATmega328P (Old Bootloader)`로
   선택합니다. 업로드에 실패하면 `ATmega328P`도 시도합니다.
4. Nano의 COM 포트를 선택하고 업로드합니다.
5. 첫 시험은 벨트를 무부하 상태로 두고 비상 시 전원을 바로 끌 수 있게
   준비합니다.

## 배선

| 기능 | Nano 핀 |
|---|---:|
| TB6612FNG PWMA | D3 |
| TB6612FNG AIN1 | D7 |
| TB6612FNG AIN2 | D8 |
| TB6612FNG STBY | D12 |
| HC-SR04 TRIG | D4 |
| HC-SR04 ECHO | D5 |

Nano, 모터 드라이버, 센서, 외부 모터 전원의 GND는 반드시 공통으로
연결해야 합니다. 모터 전원을 Nano의 5V 핀에서 직접 공급하지 마십시오.
