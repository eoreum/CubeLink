# 이오름 외부강의 블로그 자료 전달표

작성일: 2026-08-27  
목적: 최근 학교·기관 외부강의를 이오름 공식 블로그 글로 안전하고 정확하게 정리한다.

## 1. 최소 자료 — 이것만 있어도 초안을 만들 수 있습니다

1. **강의 이름 또는 주제**  
   예: 로봇공학자 진로체험, 아두이노 센서 수업, 3D프린팅 메이킹
2. **진행 시기**  
   정확한 날짜가 부담스러우면 `2026년 8월` 정도도 가능
3. **대상**  
   예: 중학교 1학년 20명, 교사 연수 15명
4. **수업 시간과 차시**  
   예: 2시간, 1회 / 4차시
5. **무엇을 했는지 3~5줄**  
   준비 활동, 학생 실습, 완성 결과, 기억에 남은 반응
6. **사진 5~15장**  
   원본 그대로 전달. 제가 게시 후보를 고르고 배치 순서를 제안합니다.

## 2. 있으면 글이 더 좋아지는 자료

- 수업계획서, 활동지, 발표자료 또는 교재
- 사용한 교구·로봇·센서 이름
- 학생들이 수행한 미션이나 만든 결과물
- 수업 중 자주 나온 질문
- 잘된 점과 다음 수업에서 바꾸고 싶은 점
- 강사 본인이 느낀 한 문장
- 기관에서 받은 후기나 담당자 의견
- 게시를 허용한 기관 공식 명칭과 홈페이지

문서는 PDF, 한글, Word, PowerPoint, 사진 촬영본 모두 괜찮습니다. 메신저에 적어둔
메모나 손글씨 사진도 사용할 수 있습니다.

## 3. 사진은 이렇게 보내주세요

가장 좋은 조합은 다음과 같습니다.

| 사진 | 권장 수 | 내용 |
|---|---:|---|
| 수업 전체 모습 | 1~2장 | 공간과 수업 분위기 |
| 준비물·교구 | 1~2장 | 오늘 무엇을 배우는지 보여주는 사진 |
| 손으로 실습하는 장면 | 2~4장 | 얼굴보다 손과 활동 중심 |
| 화면·코딩 과정 | 1~3장 | 개인정보와 내부정보가 없는 화면 |
| 결과물 | 2~4장 | 로봇 동작, 출력물, 완성 작품 |
| 마무리 장면 | 1장 | 전시, 발표, 결과 확인 |

- 가능하면 메신저의 압축 사진보다 원본 사진을 보냅니다.
- 같은 장면을 여러 각도에서 찍은 사진도 그대로 보내면 제가 선별합니다.
- 사진 속 이름표, 얼굴, 학교 표식의 공개 가능 여부를 함께 알려주세요.
- 학생 얼굴 공개 동의가 확실하지 않으면 뒷모습·손·결과물 중심 사진을 우선합니다.
- 컴퓨터 화면에는 학생 이름, 계정, 전화번호, 개인 파일 경로가 보이지 않아야 합니다.

## 4. 공개 여부 확인표

아래 항목은 `가능 / 불가 / 확인 필요` 중 하나로 알려주세요.

- 기관·학교 이름 공개
- 정확한 강의 날짜 공개
- 학생 얼굴 공개
- 학생 작품과 이름 공개
- 담당자 후기 공개
- 강의자료 일부 화면 공개
- 사용한 제품·교구 이름 공개
- 이오름의 강의 문의 안내 연결

확실하지 않은 항목은 모두 `확인 필요`로 처리하고, 글에서는 가명·일반 표현·비식별
사진을 사용합니다.

## 5. 복사해서 작성하는 간단 양식

```text
[외부강의 기록]

강의 주제:
진행 시기:
장소/기관명:
기관명 공개: 가능 / 불가 / 확인 필요
대상과 인원:
수업 시간/차시:

수업에서 한 일:
1.
2.
3.

학생들이 만든 것 또는 수행한 미션:
기억에 남은 반응이나 질문:
강사가 느낀 점:
다음에 개선하고 싶은 점:

사진 공개 범위:
- 학생 얼굴: 가능 / 불가 / 확인 필요
- 학교 표식: 가능 / 불가 / 확인 필요
- 학생 이름·작품: 가능 / 불가 / 확인 필요

첨부 파일:
- 사진:
- 수업계획서/활동지:
- 발표자료:
- 기타:
```

## 6. 제가 자료를 받은 뒤 만드는 결과물

1. 이오름 블로그 말투에 맞춘 제목 후보 3개
2. `도입 → 01~04 수업 흐름 → 배운 점` 구조의 본문
3. 사용할 사진과 배치 순서, 캡션
4. 개인정보·대외비·오래된 정보 점검표
5. 검색 태그와 카테고리 제안
6. 사용자 최종 확인용 게시 미리보기

최종 확인을 받기 전에는 블로그에 공개 게시하지 않습니다.
