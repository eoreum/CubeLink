# CubeLink Studio 로봇팔 개발 인수인계 — 2026-11-17

관리 분류: CL-02 Studio / CL-03 로봇팔. CL-01 Starter와 분리.
상태: **현장 테스트 대기**. 이 문서는 기존 대화와 저장소 문서에 근거한 점검 메모이며, 새로운 APK/EXE 빌드 또는 실물 검증 완료를 뜻하지 않는다.

## 다음 작업 우선순위
1. **Android 태블릿 시뮬레이터 전용**: 하드웨어 연결 없이 블록 실행, 3D 관절 방향/각도, 미션, 저장/재실행, 가로 화면 및 숫자 입력 확인. 미션형 웹 시뮬레이터(별도 URL)와 로봇팔 제어 앱을 혼동하지 말 것.
2. **Android 태블릿 실물 연동(실시간)**: USB-C OTG → Nano, USB 권한/자동검색/연결/재연결, 초기 안전자세, 4축 서보(D6/D9/D10/D11), 조이스틱, 초음파, 블록 실행, 3D-실물 방향 일치 확인. 태블릿 모델과 APK 버전 기록.
3. **Windows 노트북**: 기존 정상 버전 실행 → COM 선택/연결 → 펌웨어 응답 및 안전 초기화 → 블록/3D/실물 제어 → USB 재연결 → 저장/불러오기. 기존 정상 설치본을 덮어쓰지 말 것.
4. **공통 오류**: D9 하완 서보 떨림·토크, D10 방향 반전 가능성, 초기자세/그리퍼 과도 닫힘, USB 전원 및 외부 5V 공통 GND 확인. 기구를 받친 상태에서 축 하나씩 시험.
