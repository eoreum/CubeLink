## 2026-11-17 추가 확정 요구 — 11월 20일 40대 Windows USB 수업
- 40대 모두 Nano 기반, 노트북 또는 데스크톱 Windows USB 연결.
- 장비별 펌웨어 세대가 혼재. 이번 주에는 40대 펌웨어 일괄 업로드 금지. Studio에서 **기존에 확인된 프로토콜별 호환 경로**를 제공해야 한다.
- 주의: '어떤 펌웨어든 무조건 연결/실시간 제어'는 기술적으로 보장 불가. 스케치가 CubeLink 제어 명령을 지원하지 않으면 단순 포트 개방만으로 제어할 수 없다. 호환 가능한 응답/명령 규약을 식별하고, 알 수 없는 펌웨어는 '연결됨/제어 불가'로 명확히 표시한다. 무조건 서보 명령을 보내지 말 것.
- 조이스틱 장착형/미장착형 혼재. 미장착 아날로그 입력은 부동(floating)되어 허위 좌표가 생길 수 있으므로, 조이스틱 데이터 유효성/활성 상태를 판단할 수 있는 근거가 없으면 UI 중앙 고정, 임의 움직임 금지. '신호 변화 없음'만으로 부재 단정 금지. 조이스틱 유무를 선택하는 명시적 옵션을 우선 제공하고, 자동감지는 신뢰 가능한 펌웨어 기능 보고가 있을 때만 사용.
- 조이스틱 없는 장비도 Blockly → 실시간 서보 제어가 독립적으로 동작해야 한다. 조이스틱 입력을 연결 준비 조건으로 강제하지 말 것.
- 실물 1대의 안정판 검증 후 다양한 펌웨어/조이스틱 조합을 표본 시험, 이후 40대 전수 검사. 정상 수업판을 덮어쓰지 말 것.
- 호환성 매트릭스: 장비번호 / Nano 펌웨어 식별 응답 / 조이스틱 유무 / PC/COM / USB 인식 / Studio 연결 / 안전 초기화 / 코딩 제어 / 서보 4축 / 판정 / 비고.
- 교실용 우회: 호환 안 되는 펌웨어 장비는 별도 분류하고, 확인된 펌웨어 업데이트 또는 예비 장비로 대응. 연결 성공 표시와 제어 가능 상태는 반드시 구분.
- 현재 단계: 요구사항 및 시험 계획 기록. 코드 수정, 빌드, 40대 실기 검증은 아직 수행되지 않음.
