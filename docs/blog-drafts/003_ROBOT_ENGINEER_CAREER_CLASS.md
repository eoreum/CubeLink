# 보고, 조종하고, 코딩하며 만나는 로봇공학

카테고리: 진로체험·교육현장  
상태: 공개 전 사용자 검토 및 사진 공개 동의 확인 필요  
사진 제안: 로봇 구조 관찰, 조종 실습, 코딩 화면, 활동 결과를 각 1장씩 사용. 학생
얼굴과 학교 표식은 동의가 없으면 가리고, 과거 연락처가 보이는 자료는 사용하지 않는다.

---

로봇공학자는 로봇을 조종하는 사람일까요, 만드는 사람일까요?

로봇을 자세히 보고 직접 움직인 뒤 코딩으로 동작을 바꾸어 보면, 하나의 로봇 안에
기계·전자·소프트웨어가 함께 들어 있다는 사실을 자연스럽게 발견할 수 있습니다.

## 01 먼저 로봇을 관찰합니다

수업은 로봇의 겉모습을 보는 일에서 시작합니다. 바퀴나 관절은 어떻게 움직이는지,
센서는 주변의 무엇을 알아채는지, 제어 장치는 어떤 역할을 하는지 하나씩 살펴봅니다.

처음부터 어려운 용어를 외우기보다 눈앞의 움직임과 각 부품의 역할을 연결하면 로봇의
구조를 더 쉽게 이해할 수 있습니다.

## 02 직접 조종하며 움직임을 느낍니다

다음에는 로봇을 움직여 봅니다. 앞으로 가기, 방향 바꾸기, 멈추기처럼 간단한 동작도
속도와 순서를 다르게 하면 결과가 달라집니다.

학생은 예상한 움직임과 실제 움직임을 비교하면서 무게, 마찰, 균형 같은 기계적인
조건도 함께 생각하게 됩니다.

## 03 코딩으로 동작의 순서를 만듭니다

조종으로 익힌 움직임을 코딩으로 다시 표현합니다. 어떤 동작을 먼저 실행할지, 얼마나
기다릴지, 센서가 반응하면 무엇을 할지 순서대로 정합니다.

프로그램이 생각대로 움직이지 않을 때에는 실패로 끝내지 않습니다. 명령의 순서와
조건을 다시 살펴보고 한 부분씩 바꾸며 원인을 찾습니다.

## 04 로봇공학자의 일을 연결해 봅니다

하나의 로봇이 움직이기까지는 구조를 설계하는 일, 전자 부품을 연결하는 일, 움직임을
프로그래밍하는 일이 필요합니다. 또한 실제 사용자가 안전하고 편하게 사용할 수 있는지
관찰하고 개선하는 과정도 중요합니다.

이런 경험을 통해 학생은 로봇공학이 한 가지 기술로 이루어진 직업이 아니라 여러 분야의
지식과 협력이 만나는 일임을 알 수 있습니다.

보고, 조종하고, 코딩하고, 다시 고쳐 보는 시간.

진로체험은 직업의 이름을 기억하는 데서 끝나지 않고, 그 일을 하는 사람의 생각과
문제 해결 과정을 직접 경험하는 활동이 될 수 있습니다.
