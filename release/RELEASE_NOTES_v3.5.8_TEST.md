# CubeLink Studio v3.5.8 시험판

## 수정 내용

- 안전 종료 시 Studio가 기억한 각도로 10번 서보를 먼저 움직이던 중복 동작을 제거했습니다.
- 안전 종료는 기존 펌웨어의 `K` 명령을 한 번만 전송합니다.
- 실제 로봇의 현재 자세를 알고 있는 펌웨어가 현재 위치에서 보관 자세로 순차 이동합니다.
- 펌웨어는 변경하지 않으며, 현재 사용 중인 v1.4.2를 그대로 사용합니다.

## 시험 방법

1. 기존 펌웨어 v1.4.2가 설치된 로봇을 Studio v3.5.8 시험판에 연결합니다.
2. 로봇팔을 여러 자세로 움직인 뒤 `안전 종료`를 누릅니다.
3. 특히 10번 서보가 150도 방향으로 먼저 펴지지 않고 현재 위치에서 보관 방향으로 바로 움직이는지 확인합니다.
4. 보관 완료 후 모든 서보가 해제되고, 다시 연결했을 때 `SAFE`로 인식되는지 확인합니다.

실물 시험이 끝나기 전에는 학생 배포용 정식 버전으로 사용하지 마세요.
